 # คู่มือเที่ยวลาว — เว็บไซต์ตอบสนองสมัยใหม่

 โปรเจคนี้เป็นเว็บไซต์หน้าเดียว (single-page) ภาษาไทยที่นำเสนอข้อมูลการท่องเที่ยวของประเทศลาว ออกแบบให้ดูพรีเมียมด้วย Glassmorphism, การเลื่อนแบบนุ่มนวล (smooth scrolling), Parallax และตัวเลขสถิติที่แอนิเมต

 การเริ่มต้นอย่างรวดเร็ว

 1. เปิดไฟล์ `index.html` ในเบราว์เซอร์ (ไม่ต้อง build)

 ไฟล์ในโปรเจค

 - `index.html` — หน้าเว็บหลัก (Hero, สถานที่ท่องเที่ยว, อาหารและวัฒนธรรม, แกลเลอรี่, ผู้จัดทำ, Footer)
 - `css/styles.css` — สไตล์ (responsive, dark mode, glassmorphism)
 - `js/script.js` — สคริปต์ (loading, เมนู, parallax, animations)

 หมายเหตุ

 - ปัจจุบันภาพใช้ลิงก์จาก Unsplash — หากต้องการส่งงาน ให้เปลี่ยนเป็นไฟล์ในโฟลเดอร์ `assets/` และบีบอัดภาพเพื่อประสิทธิภาพ
 - แทนที่ช่องว่างข้อมูลผู้จัดทำใน `index.html` ด้วยชื่อจริง ชั้น และวิทยาลัยก่อนส่งผลงาน
 - สำหรับ production ให้เพิ่มการปรับปรุงด้านการเข้าถึง (alt text ที่ชัดเจน) และปรับขนาด/ออปติไมซ์รูปภาพ

 ต้องการให้ผมทำต่อไหม?

 - ดาวน์โหลดรูปทั้งหมดเป็นไฟล์และย้ายไป `assets/` พร้อมออปติไมซ์
 - เติมข้อมูลผู้จัดทำให้ครบและอัปเดตหน้า Contact/โซเชียล
 - เพิ่ม lightbox สำหรับ gallery หรือแผนที่แบบ interactive
